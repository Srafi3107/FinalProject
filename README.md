# HomeMatch 

AI-powered housing and roommate matching platform for urban Bangladesh

## Tech Stack
- **Frontend**: React (Vite), React Router, Axios, Chart.js (react-chartjs-2), Plain CSS / CSS variables.
- **Backend**: Node.js + Express, JWT auth, bcrypt, Multer for image uploads.
- **Database**: MySQL (mysql2), `database/schema.sql`, `database/seed.sql` with Dhaka sample data.
- **AI Service**: Python + FastAPI, scikit-learn, pandas, NumPy, joblib.
- **Scraper**: Python (requests + BeautifulSoup).
- **Locations**: Area names only (Mirpur, Dhanmondi, Uttara, Mohammadpur, Banani, Gulshan, Bashundhara, Badda, Rampura, Motijheel, etc.).
